# NORV Artificial Flowers — Premium v3

## Что реализовано
- Премиальный адаптивный каталог для мобильных устройств.
- Анимация появления блоков через GSAP.
- Плавная прокрутка через Lenis.
- Иконки Lucide.
- Категории, поиск, фильтры по формату продажи, сортировка.
- Карточка товара с розничной, упаковочной и оптовой ценой.
- Избранное и корзина с сохранением в браузере.
- Запрос заказа через WhatsApp после настройки номера.
- Админ-панель и API Cloudflare Workers + D1.
- SEO title, description и Open Graph метаданные.

## Важные ограничения текущей сборки
- GSAP, Lenis и Lucide загружаются с публичного CDN; для работы анимаций и иконок нужен интернет.
- Swup намеренно не подключён: это одностраничный каталог, а не набор отдельных HTML-страниц. Для навигации внутри каталога корректнее использовать якоря и GSAP, чтобы не усложнять мобильный сайт.
- В демо-режиме каталог использует демонстрационные товары. После настройки D1 каталог берётся из общей базы.
- Корзина и избранное пока сохраняются локально в браузере пользователя.
- Номер WhatsApp не задан. Перед включением заказов добавьте в HTML `window.NORV_WHATSAPP = "номер_в_международном_формате_без_плюса";`.
- Фотографии в демо-карточках — временные внешние изображения, замените их на реальные фотографии товаров.

## Публикация через Cloudflare с телефона
Cloudflare Dashboard Pages direct upload подходит только для статической части. Для этого проекта есть Worker API и D1, поэтому полноценная публикация требует развернуть Worker. Если вы используете только iPhone, можно воспользоваться Cloudflare Dashboard для создания D1 и Worker, но редактировать несколько файлов и конфигурацию через мобильный интерфейс неудобно. Архив включает все исходники для загрузки в GitHub и последующего подключения репозитория к Cloudflare.

## Cloudflare D1 / Worker
1. Создайте D1 database `norv-products`.
2. Выполните SQL из `schema.sql` в D1 Console.
3. В `wrangler.toml` замените `database_id`.
4. Задайте Worker secrets `ADMIN_PASSWORD` и `SESSION_SECRET`.
5. Разверните Worker с настройкой Assets из `wrangler.toml`.
6. После деплоя проверьте `/api/products` и вход в админ-панель.
